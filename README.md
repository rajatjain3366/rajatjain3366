## <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="28" /> About Me

I'm a **Computer Science student** who enjoys turning ideas into production-ready software.
I focus on **clean backend architecture**, **fast, polished frontends**, and the **DevOps tooling** that ships them reliably.

Right now I'm building **[LogPilot](https://github.com/rajatjain3366/logpilot)**, an open-source developer tool that finds places in Node.js/Express code where production failures leave no evidence, and fixes them safely after you approve each change. I measure its accuracy on code it was never tuned on, and publish the numbers.
